# Ruvin Sawmith | Portfolio

Lead Software Engineer with 9+ years of experience in C#, .NET and React.

This is a single-page portfolio (`index.html`, no build step) hosted on GitHub Pages.

## Publish it on GitHub Pages

1. Create a new public repository named `your-username.github.io` (replace with your GitHub username).
2. Upload `index.html` and `README.md` to the root of the repository.
3. Open **Settings > Pages**, set the source to **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. After a minute or two the site is live at `https://your-username.github.io`.

## Customize

- Add your LinkedIn and GitHub links in the commented block near the top of `index.html`.
- Colors and fonts are defined at the top of the `<style>` section.
